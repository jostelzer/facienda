# Facienda 0.3.0

- A new top bar understands requests, finds existing work across workspaces, and places new tasks where they belong. History shows what came in through the bar and what each request became.
- Every workspace has its own Memory page: editable entries, proposals for review, suggested next moves, and evidence-backed understanding. Background learning runs concurrently while questions take priority; older memories migrate into proposals for review.
- The board has a full-height workspace sidebar, folding group cards, calmer running signals, and coordinated transitions. Dragging a workspace into place now snaps it into line.
- Codex deliveries use the desktop app and recover queued work more reliably. Claude starts with a shorter handoff, and Settings shows the runner's model.
- Continuation suggestions follow the latest result. Helper replacement and memory migrations have additional checks.
- The experimental phone companion has been removed.

The Mac app requires macOS 26 or later. Existing workspaces are migrated when opened; keep your normal library backups.
