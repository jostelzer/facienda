# Facienda 0.6.0

- Paint workspace covers from the workspace menu. Describe what you want to see, just as you can for group covers.
- Choose a model and its reasoning level in one click. The Codex picker now includes GPT-6.2 Sol and Astra.
- Open screenshots and local previews directly from agent answers. The opened task puts the cursor in its reply field and gives you a chevron back to the board.
- Workspace memory keeps a smaller set of durable entries, learned from what you say. Agents can read it as they work.
- When Claude blocks a command you asked for, review the exact command and allow it once from Facienda. Claude's deny rules and safety checks still apply.
- Task chats show your messages and the agent's replies. Facienda sends shorter handovers and reads answers from the linked chat.

Facienda requires macOS 26 or later.
